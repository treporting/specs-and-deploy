# Demonstration of SR-09

## Requirement

SR-09: on every pull request, in .github/workflows/tools.yml, check every review result, and fail where a result breaks a rule; a pull request whose check failed cannot be merged

## Configuration

- the workflow `.github/workflows/tools.yml` and the tools as on `main` at `cad6761`
- the ruleset of `main` as in `.github/rulesets/main.json` at `e7b864b`, with the required checks
  reviewcheck, tests, schemacheck and rulesetcheck, and no bypass

## Steps

1. From `main` at `cad6761`, open a pull request with one break for each required check. For
   SR-09: a review result whose criteria RC-02 to RC-11 are missing, valid in its schema - reviews/20261027T000000_demonstration.yaml.
2. Wait until the checks of the pull request have run.
3. Read the log of the job reviewcheck, and the state of the merge of the pull request.
4. Close the pull request unmerged.

The test pull request was #235, its commit `cae8b7e`. GitHub keeps both after it is closed.

## Expected

The required check reviewcheck fails on the break, and the merge of the pull request is blocked.
