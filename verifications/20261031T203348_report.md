# Demonstration of SR_57 and SR_58

## Requirement

SR_57: in build.yml, report the test coverage of every Go module, measured with `-coverpkg=./...` over all its tests, and of every JavaScript package, without failing

SR_58: in build.yml, report as structural debt of every Go module what nothing uses - unused and unparam with `--tests=false`, and deadcode - and every function of a cyclomatic complexity of 15 and more (gocyclo), without failing

## Configuration

- the workflow `.github/workflows/build.yml`, called by the job `build` of
  `.github/workflows/tools.yml`, and `.github/build` as on `main` at `d819adc` - the merge of the
  build steps - and on the branch of the test pull request
- the ruleset of `main` as in `.github/rulesets/main.json` at `0f283dd`, with the required checks
  `build / build`, `build / lint` and `build / test`, and no bypass
- the Go module `tools`, with a package `tools/demo` added for the demonstration, and a JavaScript
  package `demo-js` with the scripts `build` and `test`

## Steps

1. From `main`, open a test pull request with three commits, one after the other, each pushed alone:
   1. `20ac5a3`: a finding of golangci-lint - an error of `os.Remove` not checked - and of eslint -
      an import never used
   2. `26411fc`: no finding; a test in Go and one in JavaScript that fail
   3. `c844d0e`: a Go file that does not compile, and a script `build` that throws
2. After each push, wait until the checks have run.
3. Read the logs of the jobs `build / build`, `build / lint`, `build / test` and `build / report`,
   and the state of the merge of the pull request.
4. Close the pull request unmerged.

The test pull request was #357. GitHub keeps it and its commits after it is closed.

## Expected

The job build / report reports the test coverage and the structural debt, and passes although it names debt; it is no required check.

Passed: `build / report` named the test coverage, two functions of a cyclomatic complexity of 15 and more and two functions no program reaches, and passed at `20ac5a3` and `26411fc`. At `c844d0e` it failed, as nothing could be measured where nothing builds; it is no required check, so it blocked nothing.
