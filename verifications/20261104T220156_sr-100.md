# Demonstration of SR_100 with pull request #490

## Requirement

SR_100: in .github/workflows/tools.yml, cancel the run of a pull request where a new push to its
branch starts another

## Configuration

- `.github/workflows/tools.yml` as on the branch `483-cancel-superseded-runs` at `6e7e6b2`: the
  group `tools-${{ github.head_ref }}` with `cancel-in-progress: true`

## Steps

1. Push the branch with `6e7e6b2` and open pull request #490; its run 41911691418 starts.
2. While it runs, push `70c3dad` to the same branch; run 41911722696 starts.
3. List the runs of the branch: `gh run list -b 483-cancel-superseded-runs`, and the jobs of the
   first: `gh run view 41911691418 --json jobs`.

## Expected

The run of the first push is cancelled when the second push starts another run; the second run
goes on.

## Observed

```
41911722696 70c3dad in_progress
41911691418 6e7e6b2 completed cancelled
```

All twelve jobs of run 41911691418 are cancelled: schemacheck, approvalcheck, reviewcheck,
uplinkcheck, tests, linkcheck, annotationcheck, rulesetcheck, build / build, build / lint,
build / test and build / report.

## Verdict

passed
